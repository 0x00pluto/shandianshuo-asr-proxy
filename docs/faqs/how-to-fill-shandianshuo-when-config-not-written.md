### **Q: 为什么启动后闪电说配置显示「未写入」，要怎么填？**

**A:**
代理会尽力改本机闪电说 `config.json` 里的 Chat 音频自定义服务商。若已有其它 Chat 音频且地址不是本代理，为避免误伤会**不改、不新建**，摘要里「配置」会写 `未写入：…`。此时按摘要下段四项在闪电说里手填即可。

**问题症状：**
- 启动摘要「配置 未写入：已有其它 Chat 音频且对不上本代理」或类似原因
- 闪电说设置里看不到「ASR Proxy 本地转写」，或仍指向别的地址

**根本原因：**
对齐策略是：只维护稳定条目，或认领「恰好一条且 endpoint 已是本代理」的 Chat 音频；多条/对不上时拒绝改写，防止每次启动多插服务商或覆盖用户其它配置。

**解决方案：**
1. 看启动摘要「闪电说自定义服务商（Chat 音频）」段。
2. 在闪电说 → 自定义服务商 → **Chat 音频** 按四项填写：
   - Base URL：摘要里的地址（默认 `http://127.0.0.1:18888/v1`）
   - API Key：`local`（若已有 Key 可沿用）
   - 模型：`medium`
3. 若摘要是「已写入/已更新自定义服务商配置」：在闪电说里**刷新设置**即可，不必手填。

**关键配置要点：**
- 对外端口以 `configs/proxy.json` 的 `port` 为准（默认 18888）
- Whisper 内部口是 `port+1`，不要填进闪电说
- 闪电说正在运行时可能覆盖刚写的 `config.json`，故成功写入后仍要刷新设置
